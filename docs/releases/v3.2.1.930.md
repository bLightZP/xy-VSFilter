# xy-VSFilter v3.2.1.930

- **Fix madVR subtitle queue draining and failure to fill while paused.** Consumer-reported frame-duration, geometry and color-context updates no longer repeatedly clear queued subtitle output.
- **Fix unnecessary queue clears when embedded subtitles arrive ahead of playback.** Future packets leave queued output intact; late packets invalidate only the affected portion of the queue.
- **Correct subtitle delivery and invalidation timing with delay or speed adjustment.** Delivered frames retain the requested video timestamps, and partial invalidation boundaries are mapped back to video time.
- **Fix stale queue tracking after seeking.** New subtitle segments reset the previous request horizon so packets after a backward seek are evaluated against the current segment.
- **Fix invalidation races during frame delivery and consumer reconnection.** Affected in-flight frames retain the correct invalidation boundary; failed deliveries and deliveries from an old connection cannot restart clears against a replacement consumer.
- **Handle zero or unavailable consumer frame durations safely.** Frame requests use the existing FPS fallback without dividing by zero or propagating a failed duration query.
